# 导入示例文件

这三个文件对应「数据导入」页里的三种类型，可以直接拿去改，也可以点页面上的
「下载模板」由系统生成同样格式的空模板。

| 文件 | 对应类型 | 说明 |
| --- | --- | --- |
| `课程库-示例.xlsx` | 课程库 | 用 Excel 写的真实例子，表头在第二行文字上必须完全一致 |
| `课程库-示例.csv` | 课程库 | 同样的内容用 CSV 写，UTF-8 与 GBK 都能识别 |
| `学生名册-示例.csv` | 学生名册 | 学院/专业/班级写**代码**，不是名称 |
| `教师名册-示例.csv` | 教师名册 | 工号即业务主键 |

## 三条规则

1. **第一行必须是表头**，文字要跟模板完全一致（多空格、全角逗号都会导致"缺少列"）。
2. **有错不入库**：系统会先把每一行检查一遍，只要有不合格的行就整体不写，
   并把问题逐行列出来（行号对着 Excel 看），改完重传即可。
3. **按业务键幂等**：课程代码、学号、工号是天然主键，
   同一份文件导第二次是**更新**而不是新增，不会把课程库导成两倍。

## CSV 用哪个编码

两种都行。系统先按 UTF-8 解，解不通再按 GBK 解——
Windows 上 Excel「另存为 CSV」默认就是 GBK，直接存直接传，不用先转编码。

## 会遇到的报错

| 报错 | 原因 |
| --- | --- |
| `表头缺少这些列：开课学院代码` | 表头文字不一致，或第一行不是表头 |
| `学院代码不存在：CS1` | 引用的代码系统里没有。点页面上的「系统里已有的代码」对照，或先在基础数据里建好 |
| `学分必须是 0.5 的整数倍（学生手册第十四条）` | 手册规定学分最小单位是 0.5，写 3.25 会被拦下 |
| `班级代码不存在：CS2301` | 新班级要先在「基础数据」里建，再导学生名册 |
